# 前端多语言开发与翻译指南

## WebUI 文案入口

WebUI 使用 TypeScript 消息表，全部在浏览器端生效：

```text
webui/src/lib/i18n.tsx            # LocaleProvider / useI18n / translate
webui/src/locales/basic.json      # 基础 catalog（类型来源 + 兜底）
webui/src/locales/zh-Hans.json    # 简体中文覆盖层
webui/src/locales/zh-Hant.json    # 繁体中文覆盖层
webui/src/locales/en-US.json      # 英文覆盖层
```

`basic.json` 是消息表的类型来源，`MessageKey` 由它推导；其余语言是同形覆盖层，由 `preloadLocale()` 按需 `import()` 懒加载。查表顺序为「当前语言覆盖层 → `basic.json` → key 原文」，因此覆盖层缺 key 时不会渲染出空白文案。

React 组件内用 `useI18n()` 取 `t`；React 之外（`lib/*`、`hooks/*`、store 等纯函数）用 `translate()`，两者查表与参数替换语义一致。不要在组件中新增硬编码的用户可见文案；涉及外部用户输入的内容必须作为 React 文本节点输出。

```tsx
import { useI18n } from "@/lib/i18n";

const { t } = useI18n();
return <h1>{t("settings.title")}</h1>;
```

语言选择优先级为 `localStorage["twilight:locale"]` → 浏览器 `navigator.languages` 偏好 → 默认 `zh-Hans`，切换时同步 `document.documentElement.lang`。当前语言是纯客户端状态，不写入后端状态，也不存在服务端语言协商；新增语言需要在 `supportedLocales`、`localeLabels` / `localeShortLabels` 和 `preloadLocale` 三处登记。

## 新增文案

1. 为稳定业务语义命名 key，例如 `emailAdmin.emptyPending`，不要把显示文本作为 key。
2. 新 key 必须先写入 `basic.json`（类型来源），再按需要写入各语言覆盖层；只改覆盖层会留下类型缺口与不一致的兜底语言。
3. 参数使用明确的替换 helper 或在页面中先格式化，用户输入只能作为参数值，不能参与动态属性名或 HTML 片段拼接。

## 转义与安全

- 用户名、媒体标题、工单正文、管理员备注和外部 API 返回值必须作为 React 文本节点渲染，禁止用 `dangerouslySetInnerHTML` 拼接 HTML 字符串；确有富文本需求时走 `@/lib/safe-render` 的白名单 renderer（当前用于公告正文）。
- 链接与图片地址只能来自固定应用路径或经过 `@/lib/safe-url` 校验的值（`sanitizeExternalUrl` / `sanitizeImageUrl` / `normalizeBackgroundImageValue`）；不要把未校验的用户输入放进 `href`、`src` 或 CSS。
- 敏感配置、Token、密码和邮箱验证码不得进入消息表、URL 或浏览器持久化存储。
- 读取接口统一使用 `cache: "no-store"`；语言 catalog 是构建产物的一部分，不应引入用户相关缓存键。

## 文本布局稳定性

Firefox 是桌面、手机、平板和窄 F12 视口基准。任何语言的文本都必须满足：

- 按钮和输入控件使用稳定的最小高度，允许标签换行，父元素设置 `min-width: 0` 和 `max-width: 100%`。
- 顶部导航、Tabs、工具栏在窄视口独立滚动或堆叠，不能用固定宽度把文字挤出页面。
- 表格保留列语义并在自己的滚动容器中横向滚动；长标题、用户名、注册码和工单编号使用安全断词。
- 对话框、下拉菜单和侧栏使用有界 `dvh` 高度、`overscroll-behavior` 以及 Firefox 标准滚动条。
- 不使用负字间距，也不通过 `vw` 任意缩放字号；标题级别应与容器密度匹配。

## 日期和数字

日期、数量和金额由组件使用 `Intl.DateTimeFormat` / `Intl.NumberFormat` 格式化后展示。不要把本地化日期写入后端状态，也不要用字符串替换模拟复数规则。API 的时间戳、UID 和计数仍按后端契约传输。

## 检查清单

- [ ] 文案未包含真实 Token、密码、邮箱验证码或服务器地址。
- [ ] 用户输入仍作为文本渲染，没有新增 `dangerouslySetInnerHTML`。
- [ ] 新增 key 已写入 `basic.json`，并按需同步目标语言覆盖层。
- [ ] 长文案在窄 Firefox 视口可换行或在所属容器滚动。
- [ ] 已运行 `pnpm --dir webui typecheck`、`pnpm --dir webui lint` 和 `pnpm --dir webui build`。
