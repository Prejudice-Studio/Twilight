### 问题清单

#### 已修复严重问题

**旧交互 timer 可能删除替换后的新状态**

- 位置：`internal/api/telegram_js_interactions.go`
- 问题：仅调用 `Timer.Stop()` 无法阻止已经开始执行的旧 callback。相同 token/key 被替换时，旧回调可能删除新条目，waiter 还可能误发旧超时消息。
- 修复：每次保存分配单调 generation；timer 只有在 generation 与当前条目一致时才能删除状态或发送超时回复。
- 证据：`TestDeveloperJSReplacedInteractionIgnoresOldTimerGeneration`。

#### 已完成性能与资源改进

- `/emby` 首次探活预算由 5 秒降至 1.5 秒，按 URL 与 Token 的哈希身份短期缓存，配置变化自动失效。
- Telegram 用户搜索改为 Store 层 UID 顺序扫描并在 limit 处停止，取消完整用户切片复制与排序。
- 面板、JS callback/waiter、销号确认状态增加容量上限、过期清理和最早到期淘汰；淘汰时停止 timer。
